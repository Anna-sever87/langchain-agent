# langchain-agent

Учебный проект: базовый агент на LangChain с собственным инструментом, структурированным ответом и памятью диалога.

## Что делает агент

HR-помощник отвечает на вопросы про отпуск. Правило компании: 28 календарных дней в год. Когда пользователь спрашивает, сколько дней накопилось за отработанные месяцы, агент сам вызывает свой инструмент `calculate_vacation_days`.

## Из чего состоит агент

| Часть | Как реализовано |
| --- | --- |
| Модель | `ChatOpenAI`, модель `gpt-4o-mini`, `max_tokens=1500` |
| Системный промпт | Роль HR-помощника, правило про 28 дней, запрет выдумывать |
| Свой tool | `calculate_vacation_days(months_worked)` считает дни отпуска за месяцы (28 / 12 за каждый месяц) |
| Структурированный ответ | `dataclass ResponseFormat` с полями `answer` и `vacation_days`, подключён через `ToolStrategy` |
| Память | `InMemorySaver` (чекпоинтер LangGraph), диалоги разделяются по `thread_id` |

## Установка и запуск

```
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и впишите свой ключ OpenAI:

```
OPENAI_API_KEY=your_openai_api_key_here
```

Запуск:

```
python main.py
```

## Пример работы

Скрипт задаёт три вопроса: два в диалоге `hr-1` и один в новом диалоге `hr-2`.

```
[диалог hr-1] Вопрос: Сколько дней отпуска мне положено, если я отработала 6 месяцев?
Ответ: За 6 месяцев вам положено 14 календарных дней отпуска.
Дней отпуска (структурно): 14.0

[диалог hr-1] Вопрос: Что я только что спрашивала? Напомни вопрос и ответ одной фразой.
Ответ: Вы спрашивали, сколько дней отпуска вам положено за 6 месяцев, и я ответил, что 14 календарных дней.
Дней отпуска (структурно): None

[диалог hr-2] Вопрос: Что я только что спрашивала? Напомни вопрос и ответ одной фразой.
Ответ: Это начало диалога, и я ничего не помню.
Дней отпуска (структурно): None
```

Что это показывает:

- tool сработал: 28 / 12 * 6 = 14 дней, агент не считал в уме;
- ответ приходит как объект `ResponseFormat`, без разбора текста;
- в диалоге `hr-1` агент помнит предыдущее сообщение, в новом `hr-2` памяти нет.

## Замечание

Предупреждение `Deserializing unregistered type ...` выводит библиотека LangGraph про будущие версии. На работу агента оно не влияет.
